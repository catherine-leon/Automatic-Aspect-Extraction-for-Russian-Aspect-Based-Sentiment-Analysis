# Models

Pretrained model files are not included in the repository.

The experiments use:

- pretrained Russian Word2Vec embeddings in the RusVectōrēs format;
- pretrained Russian FastText embeddings;
- Russian SynTagRus UD 2.5 UDPipe model;
- `DeepPavlov/rubert-base-cased` from Hugging Face.

Update the model paths in the notebooks to match your local environment.
