# Data

The datasets used in the thesis are not redistributed in this repository.

The experiments use:

- SemEval 2016 Russian restaurant ABSA training data (`se16_ru_rest_train.xml`)
- SemEval 2016 Russian restaurant ABSA test data (`RU_REST_SB1_TEST.xml.B`)
- SentiRuEval restaurant data (`SentiRuEval_rest_train.xml`)

The notebooks also use external Russian sentiment lexicons. Obtain the required resources from their official distributions and update local paths in the notebooks before execution.
